# 截影（Jieying）功能说明

截影是一款 Windows 截图工具，集截图、标注、贴图、文字识别、长截图、录屏于一体。除「翻译」外，所有功能都在本机离线完成。

适用系统：Windows 10 / 11（64 位）。

## 1. 截图

### 开始截图的方式

| 方式 | 说明 |
|---|---|
| 全局快捷键 | 默认 **F1**（方案二为 Ctrl+1） |
| 单击托盘图标 | 立即开始截图 |
| 托盘菜单「截图」 | 同上 |
| 托盘菜单「截取全屏」 | 鼠标所在的整块屏幕直接被选中，可再调整 |
| 快捷键「截取当前窗口」 | 当前活动窗口直接被选中（默认未设置快捷键，可在设置里指定） |
| 托盘菜单「重截上次选区」 | 在同一显示器、同一选区截取当前画面，按设置直接复制、保存或贴图。可绑定全局快捷键 |
| 托盘菜单「延时截图」 | 3 / 5 / 10 秒后开始，便于截下拉菜单、悬停提示 |
| 托盘菜单「自由形状截图」 | 手绘任意形状，见下文 |
| 命令行 `jieying.exe --capture` | 程序已在运行时，由正在运行的截影开始截图 |

重截会保留自由形状的边界。选区记录保留到本次截影退出为止。显示器不可用或原选区已超出屏幕范围时，需要重新选择截图区域。

### 选择区域

- **智能识别窗口和控件**：鼠标悬停时自动高亮其下的窗口或控件，单击即可选中。
- **拖动框选**：按住鼠标拖出任意矩形。
- **调整选区**：拖动边和角改变大小，拖动选区内部移动位置。
- **微调**：方向键或 **W/A/S/D** 每次移动 1 像素，加 **Shift** 每次 10 像素。
- **尺寸标签**：选区左上角实时显示宽 × 高（物理像素）。
- **重新选择**：右键清除选区回到初始状态；再右键或 **Esc** 退出截图。
- **多显示器**：每块屏幕各自冻结画面，可以在任一屏幕上选择。

### 放大镜与取色

- 选区时显示放大镜：放大的像素网格、当前坐标、颜色值（可在设置里关闭）。
- **C**：复制鼠标下像素的颜色值。
- **Shift**：在 HEX（`#RRGGBB`）和 RGB（`R, G, B`）两种格式间切换，C 按当前格式复制。

### 自由形状截图

- 截图时按 **F**，或在托盘菜单选「自由形状截图」。
- 按住鼠标画出任意形状，松开即成为选区。
- 结果图片为形状的外接矩形，**形状外部透明**；保存为 PNG 或贴图时保留透明。
- 形状可以整体拖动、正常标注，但不能拉伸边缘。再按 **F** 切回矩形选区。

### 完成截图

| 操作 | 按键 / 按钮 |
|---|---|
| 复制到剪贴板 | Enter、Ctrl+C、双击选区、工具栏 ✓ |
| 保存 | Ctrl+S |
| 直接保存到保存文件夹（不弹窗） | Ctrl+Shift+S |
| 贴到桌面 | Ctrl+T |
| 识别文字 | Ctrl+O 或 O |
| 一键打码 | Ctrl+D |
| 美化 | Ctrl+B |
| 长截图 | Ctrl+L |
| 录制 GIF / MP4 | Ctrl+R / Ctrl+Shift+R |
| 取消 | Esc、右键 |

Enter 和双击默认是「复制」，可在设置里改成「保存」或「贴到桌面」。

## 2. 标注

选好区域后，标注工具和截图输出操作分区显示，当前工具的选项在标注工具下方展开。工具栏会根据屏幕可用空间靠近选区显示，窄屏上会换行。所有标注都可**撤销 / 重做**（Ctrl+Z / Ctrl+Y，Ctrl+Shift+Z 也是重做）。

### 工具

| 工具 | Ctrl 快捷键 | Shift 备选快捷键 | 说明 |
|---|---|---|---|
| 矩形 | Ctrl+1 | Shift+1 | 按住 Shift 画正方形 |
| 椭圆 | Ctrl+2 | — | 按住 Shift 画圆 |
| 直线 | Ctrl+8 | Shift+2 | 按住 Shift 对齐到 45° 的倍数 |
| 箭头 | Ctrl+3 | Shift+3 | 按住 Shift 对齐到 45° 的倍数 |
| 尺子 | — | — | 标出线段的像素长度；斜线同时显示横纵分量，如「150 px (120 × 90)」 |
| 画笔 | Ctrl+4 | Shift+5 | 按住 Shift 画直线 |
| 荧光笔 | Ctrl+9 | Shift+6 | 半透明、正片叠底，底下的黑字不会被盖住；宽度随字号档位 |
| 聚光 | — | — | 框出一处或多处重点，让周围变暗 |
| 文字 | Ctrl+5 | Shift+8 | 点击处输入，支持多行和中文输入法；Esc 或点击别处完成 |
| 马赛克 | Ctrl+6 | Shift+7 | 框选区域像素化 |
| 模糊 | Ctrl+0 | — | 框选区域高斯式模糊，比马赛克柔和 |
| 序号 | Ctrl+7 | Shift+4 | 点击放置自动递增的编号圆点 |
| 橡皮擦 | — | Shift+9 | 点击或划过即删除标注；一次划动算一步，可一次撤销 |

### 样式

- **颜色**：8 种预设色（红、橙、黄、绿、蓝、紫、黑、白）。
- **粗细 / 字号**：小、中、大三档。
- **填充**（油漆桶按钮）：矩形、椭圆变为实心；文字带圆角底色，字色自动取黑或白以保证可读。
- 工具栏里选的颜色、粗细、填充会记住，作为下次的默认值。

### 编辑已有标注

- 点击标注即选中（虚线框），可拖动移动。
- 选中后点颜色 / 粗细 / 填充，即修改该标注。
- **Delete / Backspace** 删除选中的标注。
- **双击文字标注**重新编辑文字。
- 第一次 Esc 只取消选中，不会退出截图。

选择「聚光」后拖出矩形，可以继续框出其他重点。聚光效果会随截图一起复制或保存。支持移动、缩放和撤销。

## 3. 一键打码

- 工具栏盾牌按钮，或 **Ctrl+D**。
- 离线识别选区内的文字，自动给以下内容打马赛克：

| 类型 | 识别规则 |
|---|---|
| 手机号 | 中国大陆手机号，支持 +86 前缀和 3-4-4 分组（空格或短横线） |
| 固定电话 | 带区号，如 010-12345678、0755-1234567 |
| 邮箱 | 常见邮箱格式 |
| 身份证号 | 18 位，**校验最后一位**，校验不通过的长数字不会被打码 |
| 银行卡号 | 13–19 位，可分组书写，**须通过 Luhn 校验** |
| IP 地址 | IPv4 |

- 普通数字（价格、日期、版本号、订单号）不会被误打码。
- 全部打码算一步操作，**Ctrl+Z 一次撤销**。
- 完成后在屏幕上方提示打码了几处；没找到时也会提示。
- 位置是按字符宽度估算的，宁可多盖一点也不漏盖。

## 4. 截图美化

- 截图工具栏「美化」（Ctrl+B），或贴图右键「美化…」。
- 给截图加背景、边距、圆角、阴影，适合放进文档、文章和社交媒体。
- **背景**：透明、海蓝渐变、日落渐变、薄荷渐变、紫罗兰渐变、深灰渐变、白色。
- **边距、圆角**可调；**阴影**可开关；实时预览。
- 结果可直接复制、保存或贴图；高分屏截图保持清晰。

## 5. 文字识别、二维码与翻译

### 文字识别（OCR）

- 截图时 Ctrl+O / O，或贴图右键「识别文字」。
- **识别引擎**：
  - **PaddleOCR PP-OCRv5（默认）**：中英文混排、深色背景、符号识别更准，首次识别加载模型约 1 秒。
  - **Windows 系统 OCR**：缺少 PaddleOCR 组件或出错时自动退回使用。
- **结果窗口**：左侧原图标出每一行文字，**点击左侧的行即定位到对应文字**；右侧文字可直接修改后再复制。
- 可设置「识别完成后自动复制文字」。
- **长截图识别**：很高的图片按 2300 像素一段、上下重叠切分识别，不会因整体缩小而认不出字，重叠处不会重复也不会漏行。

### 表格识别

截取带清晰行列边线的表格，打开文字识别窗口并点「识别表格…」。在预览中检查和编辑单元格，点「复制到 Excel」，再在 Excel 的目标单元格粘贴。无法可靠分列时，预览会用单列表格呈现识别出的文字。

### 二维码 / 条形码

- 识别文字的同时自动识别图中的二维码和各种条形码（ZXing-cpp），支持任意角度和反色。
- 码的内容列在文字上方，链接可直接打开；图中用绿框标出位置。
- 二维码内部的图案不会被误当成文字。

### 翻译

- 识别窗口点「翻译」，译文显示在原文下方，可「复制译文」。
- **方向自动判断**：中文译成英文，其他语言译成中文。
- **支持的服务**（需使用者自己申请密钥）：
  - **百度翻译**：在百度翻译开放平台开通「通用文本翻译」，填写 APP ID 和密钥。
  - **腾讯云机器翻译**：在腾讯云开通机器翻译，填写 SecretId、SecretKey，地域默认 ap-guangzhou。
- 设置页有「测试」按钮，可立即验证密钥是否可用。
- 密钥用 Windows 账户加密（DPAPI）保存在本机，设置界面不回显已保存的密钥。
- 第一次翻译前会提示「文字将发送给所选服务商」，确认后不再询问。
- 长文本按行自动分段发送，遵守免费额度的频率限制。
- 免费额度和收费以服务商官网为准。

## 6. 长截图

- 截图工具栏「长截图」（Ctrl+L），或给「长截图」设置快捷键后直接框选。
- 框选后在区域内滚动内容（滚轮或拖滚动条），右侧面板实时预览拼接结果。
- **自动识别方向**：向下滚就竖向拼接，向右滚就横向拼接（宽表格、时间线），无需选择。
- **固定栏只保留一份**：顶部固定导航栏（竖向）或左侧固定栏（横向）不会重复出现；滚动条不影响拼接。
- **自动滚动**：点面板上的「自动滚动」，程序每 0.35 秒滚一格并拼接；到头、移动鼠标、选区太矮或达到最大长度时自动停止。只在点按钮后才会模拟滚轮。
- 滚太快接不上时，面板会提示往回滚一点，接上后继续。
- **最大长度**按像素总量控制，避免占用过多内存：1080p 宽度约 30000 像素，4K 宽度约 15625 像素。
- 完成后可复制、保存、贴图或识别文字；Enter 等同复制，Esc 取消。

## 7. 录屏

- 截图工具栏「录屏」：Ctrl+R 录 GIF，Ctrl+Shift+R 录 MP4；也可给「录制 GIF / MP4」设置快捷键后直接框选。
- 录制时区域外有红色边框，旁边是控制面板：计时、格式、暂停 / 继续、停止、取消。控制面板不会被录进视频。
- 控制面板挡住内容时：按住左侧圆点把手（或面板空白处）拖到别处；点最右边的「‹」收起成只剩计时的小条，点「›」展开。收起状态下次录制时保留。
- 再按一次截图或录屏快捷键也能停止。
- 录制中边录边写入磁盘，时长不受内存限制（安全上限 10 分钟）；暂停的时间不计入视频。
- 停止后按保存设置保存，或弹出保存对话框。

### 格式

| 格式 | 说明 |
|---|---|
| GIF | 自研编码器，每帧自适应调色板、只存变化区域、无限循环；帧率可设（建议 10–15 帧） |
| MP4 | H.264（优先显卡硬件编码），帧率 10–60 可设，画质低 / 中 / 高三档；区域小于 32 像素会自动补边 |

### 声音（仅 MP4）

- 可录**系统声音**（电脑播放的声音）和**麦克风**，两者自动混音，AAC 编码。
- 默认只录系统声音，不录麦克风。
- 录制面板上的**喇叭、麦克风按钮**可随时开关，并记住作为下次默认。
- 麦克风只在打开时才占用，不会一直显示「麦克风使用中」。
- 没声音的时候自动补静音，音画始终同步。

### 教程辅助

- **显示鼠标点击**（默认开）：左键点击处出现蓝色扩散光圈，右键为橙色；按住时显示实心圆。
- **显示按下的快捷键**（默认关）：画面底部显示组合键，如「Ctrl + C」，以及 Enter、F5、方向键等功能键。**普通打字不会显示**，避免录进密码等内容。
- **录入鼠标指针**可开关。

### 采集方式

- **自动（推荐）**：Windows 11 使用 Windows.Graphics.Capture（显卡合成画面，大区域、高帧率流畅）；Windows 10 区域较小时用 GDI，GDI 跟不上帧率时才改用 Windows.Graphics.Capture。
- Windows 10 上 Windows.Graphics.Capture 会在屏幕四周显示黄色边框，这是系统行为。
- 也可在设置里强制选择其中一种。

## 8. 贴图

把图片置顶「贴」在桌面上，方便对照参考。

### 贴图的来源

- 截图后 Ctrl+T，或在长截图、美化窗口里选「贴图」。
- **F3**（方案二为 Ctrl+2）贴出剪贴板内容：
  - 图片；
  - 在资源管理器里复制的**图片文件**（可多张，依次错开排列）；
  - **文字**：渲染成图片贴出；
  - **颜色代码**（`#FF8800`、`rgb(10, 20, 30)` 等）：贴出色块，标注 HEX 和 RGB。
- 把图片文件**拖到已有贴图上**，在落点再贴出。
- 托盘「最近截图」重新贴出历史截图。

### 贴图操作

| 操作 | 方式 |
|---|---|
| 移动 | 拖动 |
| 快捷工具条 | 鼠标移到贴图上缘，可直接复制、锁定位置、调整不透明度或打开更多操作 |
| 锁定位置 | 右键勾选「锁定位置」以防误拖，再次点击可解锁。锁定期间仍可右键复制和另存为 |
| 缩放 | 滚轮（以鼠标处为中心）；Ctrl+0 恢复原始大小 |
| 不透明度 | Ctrl+滚轮、Ctrl+加号 / 减号，或右键菜单 100% / 80% / 60% / 40% |
| 旋转 | R 顺时针 90°，Shift+R 逆时针 90° |
| 翻转 | H 水平翻转，V 垂直翻转 |
| 裁剪 | X 或右键「裁剪…」，拖选要保留的部分，Enter 或双击确认，Esc 取消；保留部分停在原位 |
| 鼠标穿透 | P 或 F4：点击直接穿过贴图作用到下面的窗口（贴图边框变为虚线）；从托盘「恢复贴图的鼠标操作」取消 |
| 继续标注 | Ctrl+E 或右键「标注…」，用截图标注工具在贴图上继续画 |
| 复制 | Ctrl+C |
| 另存为 | Ctrl+S |
| 识别文字 / 美化 | 右键菜单 |
| 关闭 | Esc、Delete、双击 |

滚轮与 Ctrl+滚轮在「设置」→「常规」分别配置，可选缩放、调整不透明度或禁用。表中是默认操作。

### 实时窗口贴图

从托盘打开「实时窗口贴图…」，选择要观察的窗口。置顶预览会随源窗口更新，并可调整大小。源窗口最小化时预览暂停，恢复后继续。需要留下一帧时，点「冻结为图片」将它转成普通贴图，保留原始像素和预览大小。

### 贴图分组

- 每张贴图属于一个分组，**屏幕上只显示当前分组**。
- **Ctrl+F3**：切换到下一组，鼠标旁提示「贴图分组 2 · 3 张」。最后一组之后会切到一个空组，屏幕清空，方便开始新一批；在空组上再切换回到第 1 组。
- 托盘「贴图分组」：查看各组张数、直接切换、新建空分组。
- 贴图右键「移到分组」：移到已有分组或新分组。
- 新贴图进入当前分组。
- **Shift+F3**：隐藏 / 显示当前分组的贴图。
- 在托盘菜单选择「恢复最近关闭的贴图」，即可找回本次运行中最后关闭的一张，保留位置、缩放、不透明度和位置锁定，并切回原分组。恢复后可直接用鼠标操作。
- 托盘「关闭全部贴图」：关闭所有分组的贴图。

## 9. 截图历史

- 每次截图（复制、保存、贴图、识别等）自动在本机保留一份，默认最近 **20 张**，可设 0–200 张，0 为不保留。
- 托盘「最近截图」：带缩略图，点击即重新贴出；可打开历史文件夹或清空历史。
- 托盘「最近截图」→「打开截图历史…」显示大图预览。用方向键选择条目，可复制（Ctrl+C）、另存为（Ctrl+S）或重新贴出。
- 按住 Ctrl 点击可多选，按住 Shift 可选中连续记录。点「拼排所选…」，按列表从上到下的顺序把选中的截图追加到拼排窗口，然后可调整顺序和间距。
- 卸载时自动删除历史。

## 10. 保存

### 多图拼排

从托盘打开「多图拼排…」，拖入本地图片或用文件选择添加。调整图片顺序、横排或竖排以及间距，确认预览后导出 PNG。导出保留各张图片的原始像素尺寸，间距和补齐区域透明。

- **格式**：PNG（无损，默认）、JPG、WebP；JPG / WebP 质量 1–100% 可调。保存对话框里还可以选 BMP。
- **保存位置**：
  - 默认每次询问保存位置（从保存文件夹开始）；
  - 也可设为不询问，直接存入保存文件夹；
  - 保存文件夹留空时使用上次保存的文件夹，再没有则用「图片」文件夹。
- **文件名模板**：`{ }` 里是日期时间格式（yyyy 年、MM 月、dd 日、HH 时、mm 分、ss 秒、zzz 毫秒），默认 `Jieying_{yyyyMMdd_HHmmss}`；同名时自动加 `_2`、`_3`，不会覆盖。录屏也使用这个文件名。
- **Ctrl+Shift+S**：截图时不询问，直接存入保存文件夹，并提示保存位置。
- **每次截图自动存一份**（可选）：复制、贴图、识别等操作时也自动存一份到保存文件夹。

## 13. 设置项一览

### 常规

- 开机时自动启动截影（同时处理任务管理器「启动」页里的禁用状态）。
- 回车 / 双击选区：复制到剪贴板（默认） / 保存 / 贴到桌面。
- 保留最近截图：0–200 张（默认 20）。
- 贴图滚轮、贴图 Ctrl+滚轮可分别设为缩放、调整不透明度或禁用。
- 截图时显示放大镜和颜色值。

### 快捷键

- 可开启「前台应用全屏时暂停全局快捷键」。退出全屏后自动恢复。

- 快捷键方案包括「方案一（F1 / F3）」「方案二（Ctrl+1 / Ctrl+2）」和「自定义」。
- 每个全局快捷键单独设置或清除，并实时显示「✓ 已生效」或「✗ 已被其他程序占用」。

### 保存

- 每次保存时询问位置。
- 每次截图都自动存一份到保存文件夹。
- 保存文件夹（可浏览选择）。
- 图片格式：PNG / JPG / WebP；JPG / WebP 质量。
- 文件名模板，实时显示示例。

### 标注

- 默认颜色、默认粗细 / 字号（截图工具栏里修改也会记住）。

### 文字识别

- 识别引擎：自动（推荐） / PaddleOCR / Windows 系统 OCR，并显示 PaddleOCR 是否已安装。
- 识别完成后自动复制文字。

### 翻译

- 翻译服务：不使用 / 百度翻译 / 腾讯云机器翻译。
- 对应的 APP ID、密钥，或 SecretId、SecretKey、地域；附申请入口链接。
- 「测试」按钮。

### 录屏

- GIF 帧率、MP4 帧率、MP4 画质。
- MP4 声音：录制系统声音、录制麦克风。
- 录入鼠标指针、显示鼠标点击、显示按下的快捷键。
- 采集方式：自动 / Windows.Graphics.Capture / GDI。

## 14. 安装、便携版与命令行

### 安装版

- `Jieying-<版本>-setup.exe`，**无需管理员权限**，安装到当前用户。
- 安装时可选开机自启。
- 卸载时清除设置、开机启动项和截图历史。

### 便携版

轻量便携版自带 Windows 系统 OCR 的调用支持。要使用 PaddleOCR，将同版本 `-paddleocr.zip` 中的文件解压到 `jieying.exe` 所在目录，重启截影，识别引擎选「自动」。

- `Jieying-<版本>-portable.zip`，解压即用。
- 设置保存在程序旁的 `data` 文件夹（由 `jieying.portable` 文件开启），不写注册表。

### 单实例

- 截影只运行一个实例；再次启动会把截图请求转给正在运行的截影。

### 命令行

| 参数 | 作用 |
|---|---|
| `--capture` | 开始截图（程序已在运行时由它执行） |
| `--self-check <报告文件>` | 不显示界面，检查安装是否完整，结果写入报告文件 |

自检项目包括：Qt 中文翻译、图片格式插件（PNG / JPG / WebP / GIF / ICO）、HTTPS 组件、图标渲染、Windows OCR、PaddleOCR、二维码识别、GIF 编码、MP4 编码与 AAC 音轨。

### 组件说明

- 缺少 PaddleOCR 组件（onnxruntime.dll 或 ocr-models 文件夹）时，自动改用 Windows 系统 OCR，其他功能不受影响。
- 第三方组件的许可证随程序放在 `licenses` 文件夹。

## 15. 隐私说明

- **截图、标注、文字识别、二维码识别、一键打码、长截图、录屏全部在本机离线完成**，不上传任何内容。
- **唯一会联网的功能是翻译**：只有在识别窗口点「翻译」（或设置页点「测试」）时，才把文字发送给你选的服务商；第一次使用前会征求同意。
- 翻译密钥用 Windows 账户加密保存在本机。
- 截图历史只保存在本机，可随时清空，卸载时删除。
- 录屏的按键显示只显示组合键和功能键，不显示打字内容。
- 键盘、鼠标钩子只在录屏、且开启了「显示点击 / 快捷键」时才安装，录完立即移除。
- 「自动滚动」只在你点击按钮后才模拟滚轮，移动鼠标立即停止。

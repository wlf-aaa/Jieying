# 截影 (Jieying)

Windows 截图工具：截图、贴图、标注、文字识别（OCR）、长截图、录屏（GIF / MP4）。

- **截图**：F1 截图；悬停自动识别窗口和控件；放大镜取色；回车复制。也可从托盘截全屏、截当前窗口、延时 3/5/10 秒截图；按 F（或托盘「自由形状截图」）手绘任意形状截图，形状外透明。
- **贴图**：截图或剪贴板内容（F3）贴在桌面最上层：图片、资源管理器里复制的图片文件、文字（渲染成图）、颜色代码（色块）。滚轮缩放，Ctrl+滚轮 / Ctrl+加减号调透明度，R / Shift+R 旋转，H / V 翻转，X 裁剪，P 或 F4 鼠标穿透（托盘「恢复贴图的鼠标操作」取消），Delete / Esc / 双击关闭；把图片文件拖到贴图上可再贴出；贴图分组：Ctrl+F3 切换到下一组（最后一组之后是空组，便于开始新一批），托盘「贴图分组」选组，贴图右键「移到分组」；Shift+F3 隐藏/显示当前组；贴图内 Ctrl+E 继续标注。
- **标注**：矩形、椭圆、直线、箭头、尺子（标出像素长度）、画笔、荧光笔、文字、马赛克、模糊、序号、橡皮擦；可填充实心形状、给文字加底色；按住 Shift 画正方形/圆、45° 直线；可选中移动、改色、删除，双击改文字，可撤销/重做。
- **文字识别**：默认用 PaddleOCR PP-OCRv5（中英文混排、深色背景更准），缺少时退回 Windows 系统 OCR；长截图分段识别，不会缩小到看不清。同时识别图中的二维码和条形码（ZXing-cpp）。可一键翻译（百度翻译或腾讯云机器翻译，用你自己的密钥；只在点「翻译」时联网）。
- **长截图**：框选后向下或向右滚动内容（或点「自动滚动」），自动识别方向并拼接（固定顶栏 / 左侧栏只保留一份）；最大长度按像素预算，1080p 宽约 30000 px。
- **录屏**：框选区域录制 GIF 或 MP4（硬件 H.264，AAC 声音：系统声音 / 麦克风可在设置和录屏面板上开关，默认只录系统声音）；可显示鼠标点击光圈和按下的快捷键（只显示组合键和功能键，不显示输入的文字）；Windows 11 用 Windows Graphics Capture，Windows 10 自动选最快的方式。
- **一键打码**：截图工具栏盾牌按钮或 Ctrl+D，离线识别选区文字，自动给手机号、固话、邮箱、身份证号（校验位）、银行卡号（Luhn 校验）、IP 地址打马赛克，一次 Ctrl+Z 撤销。
- **美化**：截图工具栏 Ctrl+B 或贴图右键「美化…」，加背景、圆角、阴影、边距。
- **聚光标注**可让框出的重点保持清晰，并压暗周围画面，适合突出操作步骤。
- **表格识别**可从文字识别窗口打开。带清晰网格的截图可识别成表格，校正后直接复制到 Excel。
- **实时窗口贴图**可从托盘打开。选择一个窗口后，把持续更新的画面置顶，也可把当前帧冻结成普通贴图。
- **历史**：托盘「最近截图」→「打开截图历史」可用方向键浏览、预览大图、复制、另存或重新贴出。也可按住 Ctrl 或 Shift 多选，再点「拼排所选」。默认保留 20 张。
- **多图拼排**：从托盘打开「多图拼排」，拖入图片，调整顺序、横排或竖排和间距，预览后导出透明背景的 PNG。
- **设置**：托盘图标右键「设置…」：快捷键、保存方式（PNG / JPG / WebP、文件名模板、每次截图自动存一份）、OCR 引擎、录屏帧率与声音、开机自启等。

## 默认快捷键

### 全局快捷键

截影在后台运行时也可使用。托盘右键 →「设置」→「快捷键」可更换按键或切换方案。下表为默认的方案一。

| 按键 | 作用 |
|---|---|
| `F1` | 开始截图，录屏期间按下可停止录制 |
| `F3` | 将剪贴板内容贴到桌面 |
| `Shift+F3` | 隐藏或显示当前组的贴图 |
| `Ctrl+F3` | 切换到下一组贴图 |

方案二用 `Ctrl+1` 截图、`Ctrl+2` 贴图，仍可用 `Ctrl+F3` 切换贴图分组。截取全屏、截取当前窗口、重截上次选区、长截图、录制 GIF 和录制 MP4 默认未绑定全局快捷键，可在设置里指定。

托盘「重截上次选区」会在上次截图的同一块区域截取当前画面，沿用回车确认的输出设置。

「设置」→「快捷键」可开启「前台应用全屏时暂停全局快捷键」。退出全屏后会自动恢复，仍可通过托盘菜单操作。

### 截图界面

框选后，标注工具和截图输出操作分区显示，当前工具的选项在标注工具下方展开。

| 按键 | 作用 |
|---|---|
| `Enter` | 确认截图，默认复制，可在设置中改为保存或贴图 |
| `Ctrl+C` | 复制截图 |
| `Ctrl+S` / `Ctrl+Shift+S` | 保存 / 直接存入设置的保存文件夹 |
| `Ctrl+T` | 将截图贴到桌面 |
| `Ctrl+O` / `O` | 识别文字 |
| `Ctrl+D` / `Ctrl+B` | 一键打码 / 美化截图 |
| `Ctrl+L` | 开始长截图 |
| `Ctrl+R` / `Ctrl+Shift+R` | 录制 GIF / MP4 |
| `F` | 框选前切换自由形状和矩形选区 |
| `C` / `Shift` | 复制光标下的颜色 / 在取色时切换 HEX 和 RGB |
| 方向键或 `W`、`A`、`S`、`D` | 移动选区 1 像素，按住 `Shift` 时移动 10 像素 |
| `Ctrl+Z` / `Ctrl+Y` 或 `Ctrl+Shift+Z` | 撤销 / 重做 |
| `Delete` / `Backspace` | 删除选中的标注 |
| `Ctrl+Enter` / `Esc`（编辑标注文字时） | 完成文字编辑 |
| `Esc` | 有选中的标注时取消选中，否则退出截图 |

#### 标注工具键

| 工具 | 主快捷键 | 备选快捷键 |
|---|---|---|
| 矩形 | `Ctrl+1` | `Shift+1` |
| 椭圆 | `Ctrl+2` | — |
| 箭头 | `Ctrl+3` | `Shift+3` |
| 画笔 | `Ctrl+4` | `Shift+5` |
| 文字 | `Ctrl+5` | `Shift+8` |
| 马赛克 | `Ctrl+6` | `Shift+7` |
| 序号 | `Ctrl+7` | `Shift+4` |
| 直线 | `Ctrl+8` | `Shift+2` |
| 荧光笔 | `Ctrl+9` | `Shift+6` |
| 模糊 | `Ctrl+0` | — |
| 橡皮擦 | — | `Shift+9` |

绘制时按住 `Shift` 可画正方形、圆，或将直线、箭头吸附到 45° 的整数倍。

### 贴图窗口

| 按键 | 作用 |
|---|---|
| 滚轮 / `Ctrl`+滚轮 | 缩放 / 调节不透明度 |
| `Ctrl`+加号（或 `Ctrl`+等号） / `Ctrl`+减号 | 增加 / 降低不透明度 |
| `Ctrl+0` | 恢复原始大小 |
| `R` / `Shift+R` | 顺时针 / 逆时针旋转 90° |
| `H` / `V` | 水平 / 垂直翻转 |
| `X` | 开始裁剪，拖选后按 `Enter` 确认、按 `Esc` 取消 |
| `P` / `F4` | 开启鼠标穿透，可从托盘菜单恢复鼠标操作 |
| `Ctrl+E` | 继续标注，按 `Enter` 把结果写回贴图 |
| `Ctrl+C` / `Ctrl+S` | 复制 / 另存为 |
| `Esc` / `Delete` | 关闭贴图 |

右键勾选「锁定位置」可防止误拖，再次点击解锁。在「设置」→「常规」可分别设置滚轮和 `Ctrl`+滚轮的动作为缩放、调整不透明度或禁用。

鼠标移到贴图上缘会显示快捷工具条，可复制、锁定位置、调整不透明度或打开更多操作。

托盘「恢复最近关闭的贴图」可找回本次运行中最后关掉的一张，并切回它原来的分组。

### 长截图、OCR 和美化窗口

| 窗口 | 按键与作用 |
|---|---|
| 长截图 | `Enter` 完成并复制，`Esc` 取消 |
| OCR 结果 | `Esc` 关闭 |
| 美化预览 | `Ctrl+C` 复制美化后的图片，`Esc` 关闭 |

更多用法见 [功能说明](docs/功能说明.md)。

## 构建

需要：Windows 10/11 x64、Visual Studio 2022 生成工具（C++）、Qt 6.10（msvc2022_64）。
`build.bat` 默认使用 `C:\BuildTools` 和 `D:\Qt\6.10.3\msvc2022_64`，路径不同时请修改。

```bat
powershell -ExecutionPolicy Bypass -File tools\fetch_deps.ps1   :: ONNX Runtime、PaddleOCR 模型、ZXing-cpp（可选，校验 SHA-256）
build.bat Release                                                    :: 输出 build\Release\jieying.exe
run_tests.bat                                                        :: 无界面测试（Qt offscreen，不会弹窗）
```

## 打包

需要 [Inno Setup](https://jrsoftware.org/isinfo.php) 7（或设置环境变量 `JIEYING_ISCC` 指向 `ISCC.exe`）。

```bat
powershell -ExecutionPolicy Bypass -File tools\package.ps1          :: dist\Jieying-<版本>-setup.exe 和 -portable.zip
powershell -ExecutionPolicy Bypass -File tools\verify_package.ps1   :: 静默安装/自检/卸载/便携版验证
```

- 安装包默认为当前用户安装（无需管理员），可选开机自启；卸载时清理设置和自启项。
- 便携版：解压即用，设置保存在程序旁的 `data` 文件夹（由 `jieying.portable` 文件开启）。
- 轻量便携版：运行 `tools\package.ps1 -Lite` 生成 `-lite-portable.zip` 和独立的 `-paddleocr.zip`。轻量版使用 Windows 系统 OCR。需要安装 PaddleOCR 时，将同版本组件解压到 `jieying.exe` 所在目录，重启并选择「自动」识别引擎。
- `jieying.exe --self-check <报告文件>`：不显示界面，检查安装是否完整（插件、翻译、OCR、编码器）。
- `jieying.exe --capture`：开始截图；程序已在运行时由正在运行的实例执行。
